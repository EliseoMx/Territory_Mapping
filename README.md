# Territory_Mapping

Herramienta de línea de comandos que, a partir de un listado de coordenadas en un
archivo JSON, genera una imagen del área cubierta del terreno y captura imágenes
de Street View para los puntos del recorrido.

## Uso previsto

```
Territory_Mapping.exe --input <ruta_del_json> --output <carpeta_o_archivo_de_salida>
```
